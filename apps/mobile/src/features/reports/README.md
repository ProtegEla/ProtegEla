# Feature: Reports (Mobile)

## Responsabilidade
- Formulário e modal para registrar novo incidente (RF09) com seleção de localização, categoria ("Assédio", "Violência", "Furto", "Má iluminação") e opção de anonimato.
- Interface de confirmação de relatos (aumentando confiabilidade) e denúncia de conteúdo impróprio/falso (RF07, RN06).
- Seção de comentários em escadinha (RF08).
