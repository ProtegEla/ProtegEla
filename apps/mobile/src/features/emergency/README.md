# Feature: Emergency (Mobile)

## Responsabilidade
- Botão de Pânico permanente em tela (RF14) com acionamento de emergência de alta prioridade.
- Ação Imediata: Iniciar ligação nativa para o Contato Principal (ou 190) em menos de 1 segundo (RNF09).
- Ação Secundária: Escalonamento com delay de 1,5s para montagem e abertura de mensagem no WhatsApp com link do Google Maps contendo coordenadas exatas.
- Tela com lista de números de utilidade pública (Disque 180, Polícia, Bombeiros) (RF10).
- Orientações e dicas de segurança para mulheres (RF11).
