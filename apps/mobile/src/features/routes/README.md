# Feature: Routes (Mobile)

## Responsabilidade
- Seleção de partida, destino e paradas intermediárias para pedestres (RF15).
- Comparação visual entre rota mais rápida e rota segura.
- Alerta em destaque se a rota segura exceder 30% do tempo da rota rápida (RN07).
- Modo de navegação com Foreground Service e notificação persistente (RNF04).
- Cache offline da última rota traçada (RNF03) em `src/storage/localStorage.ts`.
