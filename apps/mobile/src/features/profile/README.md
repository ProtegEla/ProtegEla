# Feature: Profile (Mobile)

## Responsabilidade
- Gerenciamento de dados da conta (username, e-mail).
- Cadastro e edição de até 3 contatos de emergência (1 principal e até 2 secundários) (RF01, RF17).
- Histórico de rotas traçadas e relatos/comentários criados pela usuária para edição/exclusão (RF04).
- Configurações de tema do aplicativo e permissão de notificações de proximidade.
- Solicitação de exclusão definitiva de conta e dados (LGPD).
